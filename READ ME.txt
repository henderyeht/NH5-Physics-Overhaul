Physics Overhaul

Double-click SimHandling.exe. Close NASCAR Heat 5 first.

Changes:
- Grip falloff
- Corner grip
- Tire stiffness
- Draft length
- Draft width
- Draft effect
- Center height

Built-in assists turned off:
- Extra grip
- Steering help
- Racing line help
- Brake help
- Brake rotation help
- Wall help
- Stability help

Still uses the game settings:
- Driving aid menu
- Garage setup
- Tire wear
- Draft strength

Competition keeps those settings. It still forces expert aids, faster wear, and lower draft strength.

The list shows each game folder. Add build picks another folder.
Apply writes this onto that folder. Remove puts these values back.
A later grip change in Engine Modifier is left in place.
